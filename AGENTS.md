# AGENTS.md

`ears` is a terminal traffic monitor (Go, single `main` package at the root).
It captures packets on one interface and shows flows, hosts, DNS, stats and a map.

## Build and test

- Build: `go build ./...` (the binary is `go build -o ears .`; `/ears` is gitignored)
- Test: `go test ./...`
- Lint: `go vet ./...`
- Format: `test -z "$(gofmt -l .)"`
- Vulnerabilities: `govulncheck ./...`
- Packet capture uses cgo via gopacket/pcap, so libpcap headers (`libpcap-dev`) are required.
- `marshal.yaml` lists these commands; `.github/workflows/ci.yml` runs the same ones.
- Go version comes from `go.mod`, and CI installs it with `go-version-file`.

## Layout

- `main.go`: flags and startup; `capture.go`: live capture and `-w` saving
- `replay.go`: `-r` replay of a saved capture
- `state.go`, `types.go`, `resolve.go`, `devices.go`, `procs.go`: traffic state and lookups
- `appproto.go`, `inspect.go`, `dns_view.go`: protocol inspection
- `topo*.go`: network map; `ui.go`, `ui_views.go`: bubbletea UI
- `explain*.go`: AI explanations using the Anthropic SDK
- `cmd/demopcap`: generator for `testdata/demo.pcap`

## Do not hand-edit

- `testdata/demo.pcap` is generated by `cmd/demopcap`.
- `demo.gif` is recorded from `demo.tape` with `vhs`.
- Running the binary needs raw-socket rights (`setcap`); tests do not.

## Learned by MARSHAL

Facts recorded by MARSHAL from its own runs, reviewed in the pull requests that added them.

- Building needs libpcap headers (`libpcap-dev`) because `capture.go` uses cgo via gopacket/pcap.
- `govulncheck` currently reports no reachable findings, only 16 in required modules the code does not call.
- `go.mod` declares `go 1.27.2` with no `toolchain` line, so CI gets that exact Go version.
